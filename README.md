# Кинотека

Фронтенд системы рекомендаций фильмов на Next.js 16, React 19, TypeScript и Zustand.

## Запуск

Нужны Node.js 20.9+ и запущенный бэкенд в `../movie_model_backend`.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

`BACKEND_API_URL` — серверный адрес бэкенда, по умолчанию `http://127.0.0.1:8000`. Локальный фронтенд доступен по http://localhost:3000. Для production-сборки: `npm run build`, затем `npm start`.

Ключ `MOVIE_TMDB_API_KEY` задаётся только в окружении бэкенда. Фронтенд получает сведения о фильмах через наш API, изображения — с `image.tmdb.org`.

## Поиск и просмотр

Главная страница показывает популярные фильмы, сериалы и анимацию из TMDB через бэкенд. Поиск не ограничен локальной БД. Результаты загружаются постранично и кэшируются бэкендом; ручной импорт не нужен.

Открытие результатов и карточек не сохраняет фильмы в БД. Для анимации в поиске фильтруется текущая страница TMDB: дополнительные совпадения могут находиться на следующих страницах. Общее число таких отфильтрованных результатов не показывается, поскольку источник его не возвращает.

## Избранное и оценки

На странице `/profiles` можно создать профиль и выбрать его для работы. Избранное и оценки 1–5 хранятся на бэкенде отдельно для каждого профиля. В браузере запоминается только выбранный UUID профиля. Профили пока не являются учётными записями: авторизация ещё не реализована.

При действии над внешней карточкой Next.js отправляет её тип и TMDB ID. Бэкенд сам находит или загружает фильм и сохраняет действие вместе с карточкой в одной транзакции. Подтверждение появляется после успешного ответа. Удаление оценки или избранного не удаляет фильм из каталога.

Если в браузере осталась коллекция `kinoteka-library-v1`, страница профилей предложит явный перенос в выбранный профиль. Перенос выполняется небольшими пакетами; повторение не создаёт дубликатов и не заменяет существующие серверные оценки. Исходная копия в браузере сохраняется.

Ссылки поддерживают UUID сохранённых карточек и числовые TMDB ID внешних карточек. Ключ экранного кэша строится по типу контента и TMDB ID. При смене профиля кэш очищается и загружается с сервера. Раздел «Для вас» объединяет рекомендации по оценкам, жанрам и описаниям фильмов выбранного профиля. Для начала без подходящих оценок возвращается популярная подборка.

## Рекомендации

Страница `/recommendations` показывает подборку для выбранного профиля. После изменения оценок и при смене профиля список загружается заново. Оценённые фильмы исключаются; сериалы пока не участвуют в модели. Неизвестные модели фильмы можно оценивать — оценки сохраняются для будущих обновлений.

Для базовой выдачи достаточно TMDB на бэкенде. ML-артефакт необязателен: для его подключения задаются `MOVIE_RECOMMENDATION_MODEL_PATH` и extra `ml`. Интерфейс различает персональный, content и популярный варианты, а частичную недоступность источников отображает отдельно. Числовые баллы не показываются как личная оценка: TMDB-рейтинг карточки относится к источнику метаданных. При сбое TMDB подборка остаётся доступной с названиями без постеров.

## Структура

- `app/` — страницы, загрузка, ошибки и 404.
- `src/api/catalog.ts` — клиент API и преобразование ответов.
- `src/api/library.ts` — клиент API профилей и библиотеки.
- `src/moviesApi.ts` — серверная точка доступа к API.
- `src/libraryActions.ts` — Server Actions для профилей, оценок, избранного и переноса.
- `src/components/` — интерфейс каталога, оценок и избранного.
- `src/store/libraryState.ts` и `libraryStore.ts` — экранный кэш коллекции выбранного профиля.
- `src/store/legacyLibraryStore.ts` — чтение прежней коллекции браузера для переноса.
- `docs/architecture.md` — архитектура и взаимодействие с бэкендом.

## Docker

Dockerfile собирает standalone-сервер Next.js с отдельным runtime-образом. BACKEND_API_URL задаётся при запуске, .env.local не попадает в образ. Для общего запуска двух соседних репозиториев выполните из movie_model_backend: `docker compose up --build -d --wait` (интерфейс — http://localhost:8080). Для модели добавьте `-f compose.yaml -f compose.model.yaml` перед up. Инструкция находится в `movie_model_backend/docs/deployment.md`.
